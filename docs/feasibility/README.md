# Feasibility history

- [Gate 1: official example, ideal baseline and wrong logical gate](gate1.md)
- [Gate 2: controlled physical faults through a public native API](gate2.md)

These reports describe the experiments before faultline-qec was scaffolded.
Their command blocks and filenames refer to that original workspace. Historical
scripts, logs, native binaries and downloaded source snapshots are not bundled
with the public repository. References to those local files are retained as
filenames, rather than links to unavailable artifacts.

The maintained implementation is in `src/faultline/`; current reproduction
commands and results are in [README](../../README.md) and
[VALIDATION](../../VALIDATION.md). The complete current pins are in
`pyproject.toml` and `uv.lock`.
