# Results

The Gate 2 sweep enumerates all 21 single faults and all 189 pairs on distinct
data qubits in each basis. The Z-only readout hides 63 of the 147 logical errors;
the paired X readout makes all visible, in agreement with the independent oracle.

The [committed sample coverage report](sample-coverage.md) is embedded below.
It records one deterministic shot per case per basis, with Z boundary 70 and X
boundary 84. See [validation](validation.md) for the broader regression checks
and [limitations](limitations.md) for interpretation.
